One image that sums up the world news of Wednesday, 18 November 2026:
a front-page infographic drawn from the day's reported headlines - the
U.S. strike on Iran's Qeshm Island and Iran's drone answer in the Gulf,
Ukraine's second strike on the Crimea Bridge, Xi hosting Putin in
Shenzhen as Trump tours Asia, the doubling Ebola outbreak in DR Congo,
and the United States losing its measles-free status after 26 years,
with the rest of the day in a ticker along the bottom. `main.py`
(standard library only) copies the committed `entry.png` to
`/output/entry.png`; `draw_image.py` is the program that drew it.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
